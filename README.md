# Semáforos em Python

Repositório com 4 exercícios práticos da disciplina de Sistemas Operacionais I, utilizando Python e a biblioteca `multiprocessing`.

## Exercícios

1. `ex01_Semaforos.py` — Gerenciamento de cruzamento.
2. `ex02_Portas.py` — Simulação de pessoas atravessando uma porta.
3. `ex03_Corrida_sapos.py` — Simulação de corrida de sapos.
4. `ex04_Formula1.py` — Simulação de treinamento de Fórmula 1.

## Tecnologias

- Python
- Multiprocessing
- Pool
- Manager
- Semaphore

## Objetivo

Praticar conceitos de processos, concorrência e sincronização utilizando semáforos.
